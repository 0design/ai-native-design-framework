# AINDF brand assets

Favicon and glyphs of the AINDF sign system. Every glyph is built from one cursor module of a single size; only its position changes.

| File | What it is |
|---|---|
| `favicon/aindf-favicon.svg` | Favicon and marketplace icon, vector |
| `favicon/aindf-favicon-1024.png` | Favicon, 1024 × 1024 PNG (plugin and catalog icon) |
| `favicon/aindf-favicon-4096.png` | Favicon, 4096 × 4096 PNG (print and large layouts) |
| `glyphs/aindf-agent.svg` | Agent: one cursor, tilted |
| `glyphs/aindf-atom.svg` | Atom / token: one cursor |
| `glyphs/aindf-component.svg` | Component: two cursors, up and down |
| `glyphs/aindf-extension.svg` | Extension: two cursors side by side |
| `glyphs/aindf-block.svg` | Block: three cursors, hollow triangle |
| `glyphs/aindf-section.svg` | Section: four cursors, triangle |
| `glyphs/aindf-overlay.svg` | Overlay: cursor with a second layer, gap equals layer thickness |
| `glyphs/aindf-core.svg` | Core / system: six cursors pointing to the centre |
| `glyphs/aindf-instance.svg` | Instance: Core with one cursor pulled out |

All glyph SVGs share one viewBox size, so the cursor module has the same size in every file.

For larger rasters, render `favicon/aindf-favicon.svg` at the size you need.
